# 项目状态与讨论决策

记录日期：2026-10-01。此文件描述已核验状态；未来方案不记作完成。

## 当前主问题

在相同 noisy 输入、候选池和数值重估器下，功能语义是否能帮助选择更可靠的表达程序，并在独立研究中提高 W/Z 恢复或稳定性？现有实验没有支持肯定结论。

## 三种概念

- Expression factor：数据支持的一组协同变化方向，具有实际 gene loadings 与 sample scores。
- Functional programme：对表达方向或基因集合的功能组织和解释；可以一对多、多对一或暂时未知。功能名字本身不是数值因子。
- Biological process coordinate：在有明确锚点的某一过程内的位置。饥饿天数不等于休眠深度，年龄不自动等于 biological age。

## 建议进入合作讨论的决策

1. 主要终点选择：恢复受控植入的 W/Z、重建留出的表达，还是保持真实扰动效应？这些目标不能由一个 PCA 弱参考指标替代。
2. 稳定但不同于 PCA 的 programme 如何获得独立支持？可比较生物重复、受控真值、已知扰动与人工审查弱参考；未匹配不应自动当作可靠负例。
3. LLM 的任务是否继续做离散 support selection，或改为排序候选/比较竞争解释？新设计必须有同证据非 LLM 对照。
4. 下一轮先固定数值候选池，控制注释存在性、文本长度与 study，分别做有语义/无语义的训练消融，再决定是否扩大规模。
5. 在独立公共研究上证明恢复收益后，再决定跨物种 identity、教师模型和外层 agent 的实验优先级。

以上是待讨论建议，尚未实施新的训练。当前 checkpoint 按 token validation loss 选取，与候选保留、支持基因及数值恢复目标不一致，建议改为多项任务级验证并记录每个 checkpoint 的行为。

## 指标解释

E02 的 41.7% 是两个研究在四档噪声下的弱参考恢复率汇总，并非 biological accuracy。原始 PCA 的 0% 来自与稀疏、重估后的参考比较，不能据此说 PCA 没有提取信号。oracle 是参考支持交集经过同一重估器得到的对照，不是全局数学上界。两个验证研究不足以支持广泛泛化结论。
