# FactorBridge 项目说明与实验回顾

合作讨论稿 · 2026 年 10 月 1 日 · 面向计算机方向合作者

我们希望从嘈杂的基因表达数据中恢复可重复的生物学变化程序，并检验 LLM 的功能知识能否改善这一过程。目前已完成两轮 Qwen 微调，数值恢复、功能证据和评估流程已接通，但尚未证明 LLM 带来恢复收益。第二轮完整语义模型在验证集上全部弃选，这是本次合作讨论的主要出发点。

这份说明重点区分任务目标、实际实现和实验结论。希望共同决定：什么才算恢复成功，怎样构造不偏向既有 PCA 的监督，以及 LLM 应承担哪部分决策。

## 1 我们要恢复什么

输入是一项研究的样本 × 基因表达矩阵，以及物种、实验方式、生物学单位等元数据。每列基因可以理解为一个观测特征；样本间变化同时包含生物过程、细胞组成、批次和测量噪声。我们希望用少数可复现的潜在方向解释其中的变化。

$$X \approx \mathbf{1}\mu^{\mathsf T} + ZW^{\mathsf T} + E$$

这里 X 有 n 个样本、g 个基因；W 为 g × k 的 gene loadings，表示每个因子涉及哪些基因及其方向和强度；Z 为 n × k 的 sample scores，表示每个样本在各因子上的位置。E 是未解释的残差。当前实现对各候选分别做 rank-1 重估，并不是联合优化整个分解，因此不同输出因子可能相关。

我们暂将 factor 定义为“在数据扰动和生物学重复下可复现的协同表达方向”。它必须有实际 W/Z；有一个 pathway 名称不等于恢复了因子。符号、排列乃至相近子空间的旋转都可能变化，跨数据比较需先对齐。统计稳定也不自动意味着因果生物学：细胞比例或批次同样可以稳定。

需要区分三个对象：expression factor 是数值方向；functional programme 是对基因集合及方向的功能解释，两者可以多对多；process coordinate 是某一有锚点过程内的位置，例如年龄或处理时间。后者不能直接称为统一的“生物时钟”。

### 当前主流程

noisy 表达矩阵 → 数值候选 → Candidate Evidence Card → Qwen 选择支持集 → 在同一 noisy 矩阵重估 → W/Z 与独立评估。

数值模块先提取 PCA 候选并按生物学单位 bootstrap。Evidence Card 给出基因 loading、排序、重复出现情况、稳定性及实验背景。第二轮还加入基因功能描述、Reactome 功能集合与富集证据，并生成少量由注释引导的子模块候选。

Qwen 输出受约束的 JSON：retain、uncertain 或 reject_null；选择卡片中实际可见的基因；引用证据并标记混杂与局限。它不直接生成矩阵，也不以猜 pathway 名称为训练目标。数值模块根据支持集从 noisy discovery 数据重估方向，再投影留出的生物学单位，得到 W/Z。若支持不足，允许无因子输出。

“输入一个数据”应指有足够独立样本及元数据的数据集；当前流程要求至少 8 个独立单位。单个样本不能独立完成这类从头发现与稳定性估计。

## 2 实际数据和训练策略

两轮实际纳入 8 个公共研究、24 个数据面板、1,371 个样本，覆盖人、小鼠和大鼠。6 个研究用于训练，2 个研究用于验证。训练研究共 1,278 个样本，验证研究共 93 个样本；目录中出现的 accession 或仅下载的文件不算已纳入训练。

训练研究：GSE113957、GSE124109、GSE132040、GSE189073、GSE193258、GSE255958。验证研究：GSE167665、GSE63577。内部 killifish 保持 frozen final test，未用于训练、调参或最终评估。现有公共验证集已用于检查与选择，不能再称作未见过的最终测试集。

数据按 study、biological unit 和 parent factor 分组。同一原始因子的各噪声版本留在同一 split；卡片数量不等于独立样本或研究数量。单位身份不完整时采用保守分组。当前噪声是在 log expression 上加入 0、0.5、1、2 倍基因标准差的噪声，非零档另屏蔽 10% 基因；这不等同于测序深度降低或所有真实平台噪声。

### 监督从哪里来

实际训练全部使用 real weak reference：从未额外加噪的公共 discovery 数据构造 PCA 和稳定性参考，再监督额外加噪后的候选。它是较少受人工扰动的参考，原始数据本身仍有噪声与混杂，不能当作 clean biological ground truth。

原始参考、目标标签和评估结果不进入模型输入；Qwen 自己的输出没有作为 gold。代码已有受控模拟模块，但这两轮 SFT 没有使用受控真值。当前 gene 标签只有被支持的正例与未标记项，没有可靠负例；混杂来源也没有有效 gold，因此相应能力没有得到充分训练。

### 模型优化

基础模型为 Qwen/Qwen3-4B-Instruct-2507，固定模型 revision。使用 4-bit NF4 QLoRA、BF16 计算，LoRA rank 16、alpha 32、dropout 0.05，适配线性层，共约 3,303 万个可训练参数。学习率 1e-4，3 epochs，microbatch 1，梯度累积 16；仅对答案 tokens 计算监督交叉熵，输入 tokens 被 mask。

实际设备为一张 RTX PRO 6000 Blackwell，nvidia-smi 显示约 96 GB 显存。模型加载、前后向及 adapter 保存重载检查已真实通过。第二轮最长样本为 9,433 tokens，配置上限 16,384，没有静默截断或丢弃。

| 项目 | E01 数值弱监督 | E02 功能语义弱监督 |
| --- | --- | --- |
| 训练与验证卡片 | 352 / 32 | 542 / 56 |
| 新增输入 | 数值稳定性证据 | 基因功能与富集等语义证据 |
| Optimizer steps | 66 | 102 |
| 训练循环耗时 | 约 7.8 分钟 | 约 98 分钟 |
| 最佳验证 token loss | 0.11653 | 0.07629 |
| 下游恢复证据 | 返回包中未提供独立比较 | 完成 9 项方法比较 |

两轮的输入和答案分布不同，loss 不能直接横向证明能力提升。E02 最佳 loss 在 epoch 2；epoch 3 回升到 0.08324。现有 checkpoint 按 token loss 选择，它与支持基因质量、候选保留及数值恢复并不是同一个目标。

## 3 已经得到什么结果

E02 已完整执行到评估结束。以下是两个验证研究在四档噪声下的弱参考恢复率，经研究内汇总后平均；参考 loading cosine 阈值为 0.7。这是与弱参考的一致性指标，不是生物学准确率，也不是 killifish 最终测试结果。

| 方法 | 弱参考恢复率 | 保留候选数 |
| --- | --- | --- |
| 原始 PCA 诊断 | 0.0% | 32 / 56 |
| Loading 支持集数值重估 | 41.7% | 56 / 56 |
| 稳定性筛选 | 41.7% | 49 / 56 |
| 相同证据的非 LLM 方法 | 29.2% | 13 / 56 |
| 功能语义规则基线 | 20.8% | 42 / 56 |
| 未微调 Qwen | 8.3% | 24 / 56 |
| 微调 Qwen 完整语义 | 0.0% | 0 / 56 |
| 同一 adapter 移除语义输入 | 41.7% | 52 / 56 |
| 同一 adapter 打乱文字 | 0.0% | 0 / 56 |

完整语义微调模型的 56 个输出全部是 uncertain 和空支持集，八个验证 view 的 W/Z 没有因子列。移除语义后，52 个 retain 中有 50 个选择全部可见基因，效果与简单数值基线持平，尚不能说明模型学会了有效的功能语义选择。

公平性仍有局限。原始 PCA 是未重估诊断，参考是稀疏支持重估方向，其 0% 不能解释为 PCA 没有信号。其余方法共享 noisy 输入、候选池和支持集重估流程。非 LLM 的 gene classifier 因只有正例监督而退化为 constant-one，仍需更强的同证据对照。

### 当前失败可以定位到哪里

第一，候选与监督不匹配。E02 新增的 190 个 programme 训练候选全部被旧 PCA 参考标为 uncertain；新增的 24 个验证候选也一样。扩展后的任务希望发现超出 PCA 的程序，但没有给这些候选任何 retain 监督。

第二，存在明显的分布关联。没有 gene-function 注释的 16 个训练例子全部 retain；有注释的 526 个例子只有 143 个 retain。GSE132040 又占训练卡片的 78.2%。模型可能依赖注释有无、结构、长度或研究差异，而非学习支持证据；这是待检验解释，尚不能归结为单一原因。

第三，低噪声时参考支持交集经相同重估器可恢复全部参考，而完整语义 Qwen 仍全部弃选，说明此时瓶颈不只在候选池。最高噪声时该 oracle 对照也降为 0，说明候选与数值恢复也有边界。此 oracle 只是指定支持集对照，并非全局数学上界。

移除语义和打乱文字都是同一 adapter 的推理干预，没有各自重新训练；同时改变的输入因素较多，不能据此断言“语义一定有害”。当前证据更直接支持重新设计监督、采样和任务级验证，而不是先扩大模型规模。

## 4 支线范围和下一轮讨论

### 已接入的功能与时间原型

功能 programme 分数已输出：以样本内基因表达秩汇总功能集合，同时报告覆盖与缺失。它反映表达层面的相对丰度，不直接代表通路活性或代谢通量。GSE113957 的 RefSeq 功能映射缺失被标为不可用，没有当作零表达。

跨物种部分得到 21 条功能对应候选，来自多个基线输出；它们不是已经验证的 factor identity，完整语义微调模型也没有贡献对应因子。跨物种配对训练和教师蒸馏有代码路径，但这两轮没有实际执行外部教师推理或多教师蒸馏，不能记作已训练的能力。

时间分析实现了 programme 到过程坐标的回归、参考曲线偏离和线性潜在状态转移，按时间留出未来观测。它仍是数值原型，没有加载外部世界模型。在 GSE124109 的 4 个噪声 view 中，状态转移仅 1 个优于均值基线；GSE132040 的 68 个组织与噪声组合中仅 11 个更好。两个验证研究没有审核通过的时间 recipe，因此没有独立验证研究的时间预测证据。

外层 agent 只保留函数接口，没有自主循环或强化学习。以后它可以组织数据审计、执行固定分析并解释结果，但不会自动解决标签偏差和不可辨识性。跨平台、分辨率识别和统一 factor graph 尚无完成证据。

### 建议共同确定的下一步

1. **先约定 factor 成功标准。** 主终点选择受控 W/Z 恢复、独立重复稳定性、留出表达预测或保留已知扰动效应，并明确哪些是辅助指标。真实弱参考一致性不能替代全部目标。
2. **让监督覆盖我们希望发现的对象。** 加入有真实支持集与混杂成分的受控模拟；真实数据继续明确标为弱参考。对不匹配 PCA 的稳定 programme 保留 unknown，避免把“未匹配旧参考”等同于已证伪。
3. **用小而明确的实验判断 LLM 增益。** 固定候选池和重估器，平衡 study 与标签，分别训练有语义和无语义版本；匹配文本长度、注释缺失与候选类型，并加入同证据的非 LLM 排序或分类对照。
4. **按任务选 checkpoint。** 同时报 retain/uncertain 分布、支持基因质量、空输出率、W/Z 恢复和 oracle 差距；在新的公共研究上验证，保留 killifish 的最终边界。仅有更低 token loss 不足以通过这一关。

这些是待讨论方案，尚未执行新训练。对计算机方向合作者，最值得参与的是部分标记监督、研究间分布偏移、受约束的集合预测，以及因子/子空间的公平评估；先明确这些问题，再决定跨物种教师或 agent 的投入。
